# ADR-011: Device-local cumulative Apple Health steps

Accepted: 2026-10-11. Extends ADR-002 without changing vital imports.

Use the installed `@kingstinct/react-native-healthkit` 14.1.0 statistics bridge. The unified optional Apple Health connection requests read access to `HKQuantityTypeIdentifierStepCount` alongside weight/BP/pulse quantities. Both entry points authorize once, persist both connection flags inside the drainable queue and preserve caches/anchors. Step history stays device-local despite the consolidated connection. Authorization completion records that access was requested; it never proves read permission. Unsupported platforms and missing native modules remain usable without connecting.

Read `queryStatisticsCollectionForQuantity` with `cumulativeSum`, unit `count`, and calendar-day or hourly intervals. The installed Swift bridge delegates to `HKStatisticsCollectionQuery` and serializes `sumQuantity`; it does not set `separateBySource`. HealthKit handles overlapping sources. Never average raw step samples or sum phone/watch source totals in JavaScript. Apple explains merged step statistics and overlapping devices in [Getting started with HealthKit, WWDC20](https://developer.apple.com/videos/play/wwdc2020/10664/); see also [statistics collection queries](https://developer.apple.com/documentation/healthkit/hkstatisticscollectionquery) and the [library source](https://github.com/kingstinct/react-native-healthkit). This API choice does not replace physical-device comparison.

Use the current device time zone consistently, matching Summary's local-calendar policy. Weeks start Monday. Day/month boundaries use local calendar constructors, not fixed 24-hour arithmetic. Day charts enumerate elapsed hourly intervals between local midnights, including both repeated DST hours; selected hour text includes its zone abbreviation. Travel creates a new zone partition and re-queries history rather than interpreting previous-zone cached totals as current-zone days.

Cache only derived totals, interval boundaries, availability and successful query time in account/zone-scoped AsyncStorage. Interval start plus zone identifies the local date; hourly timestamps distinguish repeated hours. Explicit zero is available, absent `sumQuantity` is missing. Missing access cannot be inferred from an empty result. No step samples or source identities are retained, and no step history is uploaded to Supabase or AI providers. Existing device export explicitly includes these keys; account deletion drains native work before clearing account keys. Sign-out hides account-scoped data but retains this device's cache, like existing local records.

Hydrate the cache before refreshing. On Summary launch/focus, foreground, detail open and visible-minute updates, refresh when older than one minute. Pull refresh forces a query. Revisit today plus the previous seven calendar days to catch late data, edits and deletions. Fetch older selected periods on demand, including a separate daily total for historical Day views. Serialize per-account/zone mutations, replace buckets by interval start, preserve successful cache on query failure, and ignore late UI responses after scope changes. Disconnect persists off after queued work; Health settings' existing disconnect also stops steps. No background-delivery capability is added.

Day headlines use HealthKit's daily total, independently of hourly bars. Week/month averages sum available completed daily totals and divide by their count. Include explicit zero, exclude missing days and the current partial day, show coverage, and return an empty average when no completed data exists. Display rounds the average only; totals remain visible above a goal. Goal progress caps at 100%.

The optional positive integer goal extends existing profile goal CAS/receipt persistence through migration `202610110001_optional_step_goal.sql`. Existing users remain unset. The full profile merge preserves step goals when older clients edit other fields. Existing dated nutrition/fluid snapshots remain unchanged; steps creates no streak, XP, pet, vital kind or History category.

Steps is an optional Small/Large Summary registry item using existing layout save/reorder/remove behavior. Whole-card navigation opens the hidden `/steps` route; Workout provides another detail entry point; Apple Health settings manages the consolidated connection without a separate Steps button. Explicit return parameters avoid the tab navigator's default Back destination. The detail screen exposes D/W/M/6M/Y, one orange bar chart, an absolute selection popover and accessible adjustable/keyboard actions. Six-month windows show Monday-aligned weekly daily averages (partial boundary weeks); year windows show monthly daily averages. Both end at the next month boundary and navigate by six/twelve months. Overall averages continue to use the daily denominator, not averages of grouped bars. Only pull gestures activate RefreshControl; range changes retain fixed chart geometry. No new bottom tab, graph popup or range controls on the widget.
